# SalonBoard売上明細CSV 原本アーカイブ

## このファイルについて

`salonboard_export_20260501-20260912_utf8.csv` は、SalonBoardからエクスポートされた
売上明細CSV（2026-05-01〜2026-09-12、978行・342会計）のUTF-8変換済みコピーです。

リポジトリ直下に未追跡（`.gitignore`対象外の作業ファイル）のまま置かれていた
`salonboard_utf8.csv` と同一内容（MD5: `4903d804ec75a0033e5a9fd08576543e`）を、
2026-09-13に本ディレクトリへ保全目的でコピーし、gitにコミットしたものです。

## なぜ保全するか

CSV取込パイプライン（`src/lib/import/csvImportPipeline.ts`）は取込後に生のCSVを
保持しないため、DBに反映された後は「元の明細行がどうなっていたか」を追跡する手段が
通常存在しません。

本ファイルは、サブスク決済と実施術が同一会計に混在しているケース（施術売上への
サブスク課金の混入・調査記録は久保田さんとの会話履歴参照）を**遡って特定・分離する
唯一の手がかり**であるため、誤って削除・上書きされないよう明示的にアーカイブします。

## 取り扱い上の注意

- **このファイルは書き換えない。** 新しいCSVを取り込む場合も、このファイルとは
  別名・別ファイルとして扱うこと。
- 個人情報（顧客氏名・カナ等）を含むため、外部への送信・公開リポジトリへの
  プッシュ等は既存のPII方針に準じて慎重に扱うこと（現状はプライベートリポジトリ内での保全）。
- Phase 2（既存データの遡及是正）で、このファイルの会計ID・明細行を用いて
  過去のbrain_visits治療費からサブスク課金分を分離する作業を予定している。
